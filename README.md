# Perch-data-Ivory-Coast
Data for the publication: Willmott et al., 202(6/7), Ecosphere, Proximity to continuous forest and habitat islands promotes seed rain beneath artificial bird perches in West Africa

Metadata (in column order):

SubSite - Perch within single transect

Site - 1-8 each representing one transect from a habitat island are forest

Distance - Distance of the perch along the transect in meters

Size - Size of the habitat island the transect is situated next to in meters squared

ForestDistance - Isolation of each perch from the continuous forest bordering the plantation in meters

SeedAbundance - Total number of seeds of all morphospecies collected beneath each perch

SeedRichness - Morphospecies richness

SizeFactor - Habitat island size pooled and factored into Large and Small islands, with forest size factored as Forest
